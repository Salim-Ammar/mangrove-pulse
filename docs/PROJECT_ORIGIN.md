# Project origin

Taimaa Ghazal selected the mangrove and blue-carbon theme, proposed the drone direction, and named Mangrove Pulse. She leads the team’s concept development. Salim Ammar developed the satellite-analysis workflow, evidence reviews, code and technical documentation, and presents the project.

The drone remains a concept. The implemented PoC is the satellite-evidence workflow and its inspection handoffs; neither the aircraft nor its ecological outcomes have been tested.
