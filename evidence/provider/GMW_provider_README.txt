These data form the dataset and derivatives of the Global Mangrove Watch (GMW) version 3.0. The publication reference is:

Bunting, P.; Rosenqvist, A.; Hilarides, L.; Lucas, R.M.; Thomas, T.; Tadono, T.; Worthington, T.A.; Spalding, M.; Murray, N.J.; Rebelo, L-M. Global Mangrove Extent Change 1996 – 2020: Global Mangrove Watch Version 3.0. Remote Sensing. 2022

The spatial layers are provided as both raster GeoTIFFs and vector ESRI Shapefiles. The vector layers are provided as a single geographic layer, while the raster layers are provided as 1 x 1 degree tiles where a vector layer has been provided with the tiles listed.
